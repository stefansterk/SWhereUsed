      Add your Document Manager key A free key for SOLIDWORKS customers; SWhereUsed reads your files with it.

    3. 3

    Where is this used?

    Search for a part, assembly or drawing above. You will see every assembly and drawing that uses it, and the top-level assemblies it ends up in, with quantities per configuration.

    Need to rename or move a file? Use Rename or move: every assembly and drawing that uses it is updated, with a backup, and everything is put back if anything goes wrong. SOLIDWORKS does not need to be running.

    From inside SOLIDWORKS: run the SWhereUsed macro (SWhereUsed.bas, in the app folder) with a component selected, and this page opens for that component.

    See your files in numbers: unused parts, duplicate file names, parts without a drawing and more.

        Setup

        1. Python and packages

        2. SOLIDWORKS Document Manager

        3. Document Manager license key

          A free key for SOLIDWORKS customers with an active subscription. Request it on the SOLIDWORKS key request page (choose the Document Manager key), or ask your reseller. The key belongs to your company: it is stored on this pc only and is never part of the app folder.

        4. Where to look for assemblies and drawings

          Everything (voidtools) makes this fast and finds files on every drive. Turn on its web server once: Tools, Options, HTTP Server, Enable HTTP server, port 8080.
